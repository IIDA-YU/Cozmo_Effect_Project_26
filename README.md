## 1. プロジェクト概要
本研究は、これら「高コスト・中央集権・低堅牢性」という既存ロボットの課題を打破するため、生物の「蟻（アリ）」に見られる群知能のメカニズムを応用した「仮想フェロモンによる自律分散型ロボット制御システム」を構築することを目的とする。
生物のアリは、個体としては非常に低機能でありながら、地面に化学物質（フェロモン）を分泌し、互いにその濃度を感知して追従し合うことで、結果として巣から餌場までの「最短経路」を自律的に形成する。この仕組みをソフトウェア空間上にデジタルマップ（環境側）として実装し、ロボット群と通信させることで、各ロボットは高度な地図を持たずとも、周囲の局所的なフェロモン濃度のみに基づいて移動決定を行えるようになる。これにより、機体側のセンサー・計算リソースを極限まで削ぎ落とした「超低コスト・低機能個体による高度な群制御」を実現する。


### 主な解決策
* **複数ID化による多拠点動的ルーティング:** 単一のフェロモン物質だけでなく、ソフトウェア上で「目的地A用の赤フェロモン」「目的地B用の青フェロモン」といったように、ID（あるいは周波数）を分けた複数の仮想フェロモン空間を重畳的に設計する。ロボット側は自らに割り当てられたタスクに応じて、検知・追従するフェロモンを動的に切り替えることで、同一空間内で交差する複雑な複数ルートの同時制御を実現する。
* **フェロモンの「揮発・最適化」アルゴリズムによる動的障害物回避:** フェロモンは時間経過とともに「揮発（濃度が減衰）」する。あるルートに動的な障害物が置かれ、ロボットが一時的に通れなくなると、その先のルートへのフェロモン供給が途絶え、自然と濃度が低下する。これにより、別の空いているルートを探索した個体が残したフェロモンが急速に強化され、中央サーバーによる全域再計算を挟むことなく、環境側が自律的に「最適な迂回ルート」へとシステムを誘導するプロセスを数理モデルと実験で実証する。
* **「コスト対タスク達成効率」の評価指標の確立:** 研究の評価軸として、単なる「到達精度」だけでなく、「システム全体の総ハードウェアコスト」に対する「時間あたりのタスク達成率（搬送効率）」という費用対効果の評価指標を独自に導入する。これにより、高級な配膳ロボット1台を導入するコストで、低機能ロボット10台を仮想フェロモンで稼働させた方が、結果として耐障害性や総搬送量において上回るシナリオがあることを定量的に証明する。

## 2. 想定されるユースケースと社会的・商業的有用性
* **中小規模店舗・変則レイアウトの飲食店:** 高価なSLAMロボットを導入できない個人店や、通路が狭く頻繁に椅子や人が動く環境において、機体コスト数万円以下の超軽量ロボットによる柔軟な配膳システムの構築。
* **次世代物流倉庫における超多台数ソート（仕分け・搬送）:** 1台数百万のAGVではなく、数万円のパレット搬送ロボットを数百台同時に同一フロアで走らせ、フェロモンの相互作用のみでぶつからずに効率的な荷役を行う群制御システム。
* **極限・未知環境（災害現場や宇宙探査、広大な農地）:** 事前の地図構築（マッピング）やGPS・通信インフラが利用できない環境下において、先行したロボットが仮想フェロモン（または簡易な中継無線シグナル）を環境に残し、後続がそれを辿ることで、インフラレスでの自律探索・物資搬送を可能にする。

## 3. 開発環境・実行環境
* **Pythonバージョン:** `Python 3.9.13` (Python 3.9系統一)
  * ※ Cozmo / Pycozmo 関連ライブラリの互換性・安定性のため、バージョンを統一しています。
* **セットアップ:**
  ```powershell
  # 仮想環境作成 (Python 3.9 を指定)
  py -3.9 -m venv .venv
  .\.venv\Scripts\Activate.ps1

  # ライブラリインストール
  pip install -r requirements.txt
  ```
